# 源码桌面版

开发期间不重新打包 EXE。双击项目根目录的 `启动学习助手.vbs`，使用已经安装好的独立 GUI 环境直接运行当前源码，修改保存后重开窗口即可生效。

窗口内包含图片扫码登录、本地会话恢复、课程勾选、开始与停止、每秒视频进度、服务端已保存进度和运行记录。默认使用本机 `nagi` 档案；已有会话会在打开窗口后自动验证并刷新课程，不自动开始学习。首次使用点击「登录 / 刷新课程」，需要更换账号或重新扫码时点击「重新扫码登录」。

顶部显示本学期当前在学课程数、已完成／总视频数及汇总进度；课程表分别显示平台学习进度和视频完成进度。汇总按视频个数加权，标明已统计课程数，无法读取的视频数据不按 0% 或 100% 计算。平台学习进度与视频完成比例可能不同，也不等于课程总成绩。刷新课程会重新读取这些数据；每个视频结束后重新统计该课程，所有统计保存在本地以供下次打开查看。

当前播放进度每秒更新；「服务端已保存」在平台成功接受上报后更新，两者不会混为一谈。停止或关窗会结束当前工作进程，尚未上报的秒数可能不会保存，下次会重新读取平台记录。验证码或没有明确答案的随堂题会停止，请本人处理后继续。

固定 1 倍速、跳过已完成视频、同档案单实例；不调用付费 AI，不运行正式考试或作业。学习前保持旧 Fedora 任务关闭。

开发入口：`.venv-windows-build/Scripts/pythonw.exe owner_entry.py`。本人源码入口无日期限制；`windows_entry.py` 仍是原分享入口，其静默到期限制保留。此阶段生成的改动尚未纳入旧 EXE，`dist` 中的旧包不能代表当前界面。
